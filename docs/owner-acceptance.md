# Приёмка owner-flow в production (ручной чек-лист)

Автотест `tests/owner.mjs` проходит этот путь локально с поддельным Discord и локальным NuVotifier.
Здесь — то, что проверяется только на живом `gamescout.online` после деплоя, секретов и миграции `0005`.
Нужны два Discord-аккаунта (A — владелец, B — посторонний) и сайт, на который A может положить файл.

## 1. Вход
- [ ] В модалке входа есть «Войти через Discord»; Discord спрашивает только `identify` (без email).
- [ ] После согласия возвращает на ту страницу, откуда начинали; в шапке — имя из Discord.
- [ ] «Отмена» на экране Discord → возврат с сообщением об ошибке входа, без сессии.
- [ ] Повторный вход тем же аккаунтом не создаёт второго пользователя (те же карточки в кабинете).

## 2. Добавление сервера (`/add-server`)
- [ ] Новая карточка уходит на модерацию (`PENDING_MODERATION`), в каталоге её ещё нет.
- [ ] Та же игра + то же название/сайт → «такой сервер уже есть» (`409 duplicate_server`).
- [ ] Карточка видна в `/dashboard` автора.
- [ ] Публикация: `POST /api/v1/admin/servers/:id/publish` с `ADMIN_TOKEN` → карточка в каталоге,
      в `/sitemap.xml` (если подключён маршрут Worker) или в `/api/v1/sitemap.xml`.

## 3. Подтверждение владения
- [ ] «Это мой сервер» → выдан код и путь `/.well-known/gamescout-verification.txt`.
- [ ] Без файла → «Файл недоступен»; с чужим содержимым → «токен не совпадает».
- [ ] С правильным файлом → «Подтверждено», карточка в кабинете A.
- [ ] Аккаунт B не видит заявку A (404) и не может подтвердить карточку с владельцем (`already_claimed`).
- [ ] Код старше 24 часов → «Срок действия кода истёк» (проверяется по возможности).

## 4. Права
- [ ] B не открывает статистику, ключ API, мониторинг и голосование карточки A (403/404).
- [ ] Если карточку добавил B, а подтвердил A — у B пропадает доступ к её настройкам.

## 5. Мониторинг
- [ ] Для Minecraft достаточно host/port; через ≤ 2–4 минуты статус меняется с `PENDING`.
- [ ] Приватный адрес (`127.0.0.1`, `10.x`, `localhost`) отклоняется (`invalid_target`).
- [ ] Карточка без источника показывает «Источник онлайна не подключён», а не вечное «ожидание».

## 6. Голосование
- [ ] Pull API: голос с профиля → `GET /api/v1/votes/pending` с ключом сервера его видит,
      `POST /api/v1/votes/claim` закрывает; повторный голос до кулдауна отклоняется с датой.
- [ ] NuVotifier (только Minecraft): host/port/token сохраняются, токен не возвращается обратно
      (только «токен сохранён»); голос с профиля приходит в NuVotifier (событие в логах плагина).
- [ ] NuVotifier выключен → голос остаётся в очереди; после включения доходит в течение нескольких
      тиков cron (до 3 попыток за сутки).
- [ ] Для L2/GTA/Rust поля NuVotifier не предлагаются, API отвечает `votifier_minecraft_only`.
- [ ] Публичный `/api/v1/servers/:slug/reward` отдаёт только награду и кулдаун — без host/token.

## 7. Аналитика
- [ ] Просмотр профиля, переход на сайт, «Играть» и голос увеличивают счётчики в кабинете за 7/30 дней;
      повторное действие того же посетителя в течение 30 минут счётчик не накручивает.
