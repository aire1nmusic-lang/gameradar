# Запуск личного кабинета: что осталось сделать владельцу

Состояние на 29.09.2026. Приватная часть (аккаунты, голоса, монеты, платежи, жалобы правообладателей) работает на тестовой виртуальной машине Yandex с PostgreSQL. Публичный сайт и каталог живут отдельно и не зависят от неё. Пока не выполнены пункты ниже, кнопка «Войти» на сайте сообщает, что аккаунты подключаются.

Порядок важен: каждый следующий пункт опирается на предыдущий. Секреты в чат не присылайте — их вписывают на самой машине в файл `.env` (права `0600`) и в консоли провайдеров.

## 1. Резервные копии базы (бесплатно, 10 минут)

Без проверенных копий включать реальных пользователей нельзя.

В консоли Yandex Cloud, каталог `gamescout`:

1. **Object Storage → Создать бакет.** Имя, например, `gamescout-private-backups`. Доступ на чтение, на список объектов и на настройки — **все выключены** («Ограниченный»). Класс хранилища — стандартный. **Максимальный размер — 1 ГБ.**
2. **Жизненный цикл бакета:** удалять объекты старше 14 дней.
3. **Идентификация → Сервисные аккаунты → Создать.** Имя `gamescout-backup-uploader`. Ролей на каталог не назначать.
4. Открыть бакет → **Права доступа → Настроить → Добавить.** Сервисный аккаунт `gamescout-backup-uploader`, роль **`storage.uploader`** — только на этот бакет. Никакой `storage.admin`, никаких статических ключей.
5. **Compute Cloud →** виртуальная машина → **Изменить →** сервисный аккаунт `gamescout-backup-uploader`. Сохранить.
6. Напишите мне, что готово. Я проверю по нашему скрипту `deploy/vm/backup.sh`: зашифрованный дамп уйдёт в бакет, восстановится в отдельную базу, и я включу ежедневное расписание.

Отдельно храните **закрытый ключ GPG для восстановления** вне машины (менеджер паролей и копия в другом месте). Без него копии не расшифровать.

## 2. Почта с кодами подтверждения

Нужен российский отправитель, иначе возникает передача данных за границу.

1. Зарегистрироваться в Unisender Go и подтвердить домен отправителя `gamescout.online`. Сервис покажет 2–3 записи для DNS (SPF, DKIM, иногда DMARC). **Их вносите вы** в DNS-панели домена.
2. Создать API-ключ, отправитель, например, `GameScout <no-reply@gamescout.online>`.
3. На машине в `deploy/vm/.env` задать:
   ```
   MAIL_DRIVER=unisender
   MAIL_FROM=GameScout <no-reply@gamescout.online>
   UNISENDER_API_KEY=<ключ>
   ```
4. Перезапустить API: `docker compose up -d api`. Отправить тестовое письмо на свой адрес через регистрацию.

## 3. Вход через Google, VK и Яндекс

У каждого провайдера создать приложение. Адрес возврата у всех одинаковый по шаблону:

| Провайдер | Где создать | Адрес возврата | Переменные в `.env` |
|---|---|---|---|
| Google | console.cloud.google.com → APIs & Services → Credentials → OAuth client (Web) | `https://gamescout.online/api/v1/auth/google/callback` | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |
| Яндекс | oauth.yandex.ru → Создать приложение → Веб-сервисы, доступ к e-mail не нужен | `https://gamescout.online/api/v1/auth/yandex/callback` | `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` |
| VK ID | id.vk.com → Мои приложения → Веб | `https://gamescout.online/api/v1/auth/vk/callback` | `VK_CLIENT_ID`, при наличии `VK_CLIENT_SECRET` |
| Discord (по желанию) | discord.com/developers/applications → OAuth2 | `https://gamescout.online/api/v1/auth/discord/callback` | `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET` |

Запрашиваем минимум: идентификатор, имя, аватар. Почту провайдера в аккаунт не берём: для входа по почте нужно отдельное подтверждение кодом.

Google и Discord — иностранные сервисы. Вход через них не обязателен для запуска: начать можно с почты, Яндекса и VK.

## 4. Публичный HTTPS-адрес приватного API

Шлюз Yandex должен направлять `/api/v1/auth/*`, `/api/v1/me/*`, голоса, монеты и остальное приватное в контейнер на машине. Заготовка шлюза уже в репозитории (`ru-proxy/yandex/gateway.private.template.yaml`, описание в `docs/yandex-private-gateway.md`).

1. Завести в DNS запись **A** для `priv.gamescout.online` на публичный IP виртуальной машины. Это можно вносить в Cloudflare, режим «только DNS» (серое облако).
2. В `deploy/vm/.env` задать `PRIVATE_API_HOST=priv.gamescout.online`. Caddy сам получит сертификат.
3. В группе безопасности машины открыть 80 и 443 для всех, 22 — только с вашего адреса. Порты 5432 и 8080 не открывать.
4. Проверить с любого компьютера: `https://priv.gamescout.online/api/v1/health` отвечает 200.
5. Только после этого — переключение маршрутов шлюза (делает отдельным шагом Кодекс или я, по вашему подтверждению), и **тогда же** на Cloudflare включается `PUBLIC_ONLY=true`.

Важно: настоящий IP посетителя. Caddy кладёт в заголовок адрес того, кто к нему обратился. Если перед ним стоит шлюз Yandex, там окажется адрес шлюза, и защита от накруток голосов ослабнет. Это проверяется на тестовой среде до включения.

## 5. Перед открытием для людей

- Уведомление Роскомнадзору об обработке персональных данных (оператор — вы; адрес хранения — Yandex, Россия).
- Политика обработки данных и согласие на странице регистрации.
- На Cloudflare **не** включать `ACCOUNTS_IN_D1`. Аккаунты там выключены специально: почта и пароли пользователей не должны храниться за границей.
- Отдельная проверка на готовом стенде: регистрация, вход, восстановление пароля, голос, заявка на сервер, жалоба правообладателя, отправка писем, восстановление базы из копии.
- Грант Yandex (4 000 ₽) сгорает 03.11.2026. Для машины (~1 700 ₽ в месяц) после этой даты понадобится оплата.
