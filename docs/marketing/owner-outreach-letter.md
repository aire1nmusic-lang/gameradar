# Письмо владельцам серверов — черновик

Статус: ЧЕРНОВИК. **Не отправлять, пока подтверждение прав (Claim) не работает на живом сайте** (см. docs/launch-readiness-2026-10-29.md). Иначе человек перейдёт по ссылке и не сможет сделать то, что ему предложили.

Отправляет владелец GameScout лично (Discord, Telegram, почта проекта). Массовые рассылки и спам не используем: одно сообщение одному проекту, в его официальный канал связи, с ссылкой на его же карточку.

Перед отправкой подставить:
- `[Проект]` — название сервера;
- `[ссылка]` — адрес его карточки, например `https://gamescout.online/server/donutsmp`;
- `[что в карточке]` — одно реальное наблюдение из карточки: хроника и рейты, режим или платформа, и откуда сейчас берётся онлайн. Без этого сообщение выглядит как рассылка.

## Основной текст (Discord / Telegram)

Здравствуйте! Я делаю GameScout — каталог серверов Lineage 2, Minecraft и GTA RP. [Проект] уже есть в каталоге: [ссылка]

Карточка собрана из открытых источников: [что в карточке]. Если что-то устарело — скажите, исправим.

Что может сделать владелец, бесплатно:
- подтвердить права на карточку (DNS-запись, файл на сайте или Discord) и править описание и характеристики;
- получить пометку «Проверено GameScout» для онлайна: для этого нужен API или агент на вашей стороне, мы считаем игроков сами, а не берём заявленное число.

Как мы показываем онлайн и чего не делаем: https://gamescout.online/about

Если это неинтересно — просто ответьте, больше не напишу.

## Короткий вариант (первое сообщение в Discord, где длинные тексты не читают)

Здравствуйте! [Проект] есть в каталоге GameScout: [ссылка]. Онлайн у нас всегда подписан источником; владелец может бесплатно подтвердить карточку и подключить проверенный онлайн. Подробно расскажу, если интересно.

## Добавки по играм (одна строка после основного текста)

- **Lineage 2:** у L2 нет открытого счётчика игроков, поэтому без вашего API мы показываем только «логин-сервер отвечает». С API у карточки будет точный проверенный онлайн — это заметно отличает её от соседей.
- **Minecraft:** сейчас мы видим число из ответа сервера на запрос статуса и помечаем его как LIVE. С вашим API онлайн станет проверенным.
- **GTA RP (FiveM):** если список игроков отдаётся с адреса самого сервера, мы уже можем посчитать онлайн сами — проверьте, что в карточке указан правильный адрес.

## Ответы на частые вопросы владельцев

- **Сколько стоит?** Размещение, подтверждение прав и проверка онлайна — бесплатно.
- **Можно купить место в рейтинге голосов?** Нет. Голоса считаются отдельно от поддержки за GS Coins.
- **Удалите нашу карточку.** Уточнить, что именно не устраивает; спорные ссылки и материалы — через https://gamescout.online/copyright. Карточку не удаляем молча и не скрываем данные без проверки.
- **Откуда у вас наш онлайн?** Источник и время указаны рядом с числом в карточке.
