# Coins, партнеры и эмблемы — решения 01.10.2026

## Промо вместо искусственной активности

Промо-начисления реальным пользователям (друзьям, представителям клана, стримерам) допустимы как продуктовая модель. Они не являются покупкой/выручкой, не выводятся и не передаются. Бартер требует явных условий: кто, сколько, за какую публикацию, срок, подтверждение выполнения. Оформление рекламы и налоговый учет проверяются отдельно; техническое начисление не означает юридического одобрения конкретной сделки.

В коде сейчас есть только local-only `/__dev/coins` с ADJUSTMENT/source=local-fixture. Production-интерфейса промо-раздачи НЕТ. Нельзя открывать dev route в production или менять balance без ledger. Будущая admin-операция: ADMIN-only permission, recipient, amount, campaign, reason, idempotency key, atomic ledger+balance+audit. Исправление новой записью; финансовый ledger никогда не редактировать. До включения решить публичное обозначение бонусной поддержки и учет смешанных purchased/promo Coins.

Не создавать вымышленные production-аккаунты, ники, участника «Анонимно» или поддержку, якобы исходящую от игроков. Анонимность реального пользователя — отдельная разрешенная функция. Бесплатный честный старт: реальные промо-партнеры; отдельный блок «Стартовая акция GameScout»; демонстрация с явной надписью «Тестовые данные» вне боевого рейтинга. Народный рейтинг зависит только от принятых голосов, любые Coins его не меняют.

## Изображения

Базовые знаки уже реализованы через ServerLogo: L2 — мечи, Minecraft — кирка, GTA RP — автомобиль; общий стиль и размер. В этом срезе default glyph и приглушенная палитра заменяют яркую базовую монограмму; сохраненные настройки оформления остаются выбором пользователя. Наличие src в компоненте не означает проверку владельца/оплаты: он сам не выполняет такую проверку. Нельзя продавать еще не реализованную approval-функцию.

L2 classic: clan 16×12, alliance 8×12, BMP 256 цветов; на сайте показ рядом без растягивания, увеличенный просмотр nearest-neighbor. Источник: [официальный legacy guide](https://legacy-lineage2.com/guide/guides_crests.html). Ограничения конкретных хроник/клиентов проверяются отдельно. Эти маленькие значки не подходят в качестве большого server logo.

Для Minecraft/GTA RP нет нужды придумывать универсальный игровой стандарт клана. Предлагаемая услуга GameScout: собственный логотип сообщества/команды или аватар канала, например PNG/WebP до 256×256. Это оформление страницы на нашем сайте, не продажа игровых предметов, скинов, плащей или игровых прав. Чужие игровые/корпоративные логотипы не брать для базовых эмблем. Цена не утверждена; продажи выключены.

Будущий workflow: private upload в РФ → проверка реального формата/размера/лимита, re-encode без EXIF, без SVG/HTML/анимации → ADMIN preview/approve/reject → списание AVATAR и activation в одной private транзакции → идемпотентная public projection. До одобрения старый/default знак сохраняется; при reject не списывать Coins. Copyright может обратимо скрыть конкретную эмблему. Загрузка и модерация клановых эмблем/каналов пока НЕ реализованы; команда/канал как отдельная сущность тоже отсутствует. Это следующий отдельный продуктовый срез, не повод менять рейтинг или давать VIP.

## Cookies — фактическая проверка репозитория

Баннер согласия не найден. Private API ставит gs_private_session (7 дней) и gs_private_oauth (10 минут), HttpOnly/SameSite=Lax, Secure в production; они описаны в src/data/legal.json. Настройки/избранное сохраняются в localStorage. Подключенные сторонние gtag/Метрика scripts по просмотренному source не найдены. Есть first-party POST /events в frontend: это аналитическое событие независимо от наличия cookie; фактический прием и хранение нужно проверить отдельно.

Не считать отсутствие баннера «автоматическим согласием». Практическая схема: служебные cookie описать в политике и проверить основание обработки; необязательную аналитику не запускать до выбора. Если она подключается — отдельные «Разрешить / Отказаться / Настройки», отзыв и одинаковая работоспособность без аналитики. Один обязательный «Согласен» не доказывает согласие на все обработки. Юридическое заключение о российской модели и обязательности баннера для конкретного набора данных не получено; официальный документ РКН по использованному URL не открылся. Перед открытием регистрации остается legal/RKN gate из основного roadmap.
