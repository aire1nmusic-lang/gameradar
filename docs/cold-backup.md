# Скачать зашифрованную резервную копию на ПК

Из корня `F:\GameHub`, с уже настроенным Yandex CLI:

```powershell
node scripts/download-cold-backup.mjs
```

Команда выбирает последний `.dump.gpg` из существующего private bucket, скачивает только зашифрованные байты и сверяет размер/SHA256 из metadata upload. Сохраняет в `F:\GameHub\cold-backups`, исключенный из Git. Повторный запуск проверяет существующий файл и не перезаписывает его. При несовпадении/незавершенном `.part` прекращает работу; никаких автоматических удалений.

Recovery key не загружается, БД не расшифровывается. Ключ восстановления хранить отдельно от копии, как в existing recovery runbook. Эта команда обеспечивает независимую от Yandex копию файла, но не заменяет restore rehearsal и сохранение кода/конфигурации без секретов. Пароль/ключ и копию не складывать вместе в GitHub/публичное облако.

Новые ресурсы0; чтение/трафик уже существующего Object Storage по действующему тарифу. Новая независимая копия зависит от диска ПК владельца; периодически копировать encrypted файл на отдельный носитель. Расшифрованную БД постоянно на ПК не хранить.
