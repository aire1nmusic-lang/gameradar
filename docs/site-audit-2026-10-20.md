# GameScout — обход сайта и план завершения

20 октября 2026. Исходники main c50fc7a; последний принятый релиз интерфейса 9583ce1.

## Решения владельца

1. Сейчас: выбрать и внедрить раскрытие хроник L2, проверить публичный интерфейс и мобильные сценарии.
2. Затем: уникальные картинки всех отображаемых хроник, включая «Все».
3. Затем: довести Minecraft и GTA RP до того же уровня качества.
4. После визуальных срезов: единый вход/регистрация, реальные сценарии пользователей, подключения и запуск. Регистрация общая для трёх игр, не три отдельные системы.
5. Платежи, документы и новые платные ресурсы — финальный этап. Продажи не включались.

## Три интерактивных варианта

| Вариант | Поведение | Компромисс |
|---|---|---|
| A — под поиском | Кнопка раскрывает сетку в потоке страницы. Выбор закрывает сетку и меняет выбранную эпоху. Escape закрывает, фокус возвращается к кнопке. | Самый понятный переход с текущего сайта; открытая сетка временно занимает высоту. Рекомендован. |
| B — быстрая лента | Все/Interlude/High Five/Essence доступны сразу. Дополнительная сетка открывается кнопкой «Все хроники». | Быстрее частый выбор, но постоянно занимает место над серверами. |
| C — отдельная секция | Вкладка «Хроники» заменяет область серверов сеткой. Выбор или «К серверам» возвращает список. | Крупнее картинки; требуется дополнительное переключение раздела. |

Каждый HTML самодостаточен: картинки встроены, интернет не нужен. Данные серверов демонстрационные. Это макеты взаимодействия, не копия всех функций сайта и не новая публикация production. Иллюстрации из текущего сайта временные; Gracia повторяет High Five намеренно до следующего этапа картинок.

Проверено в браузере: все 3 варианта на 320×568, 390×844, 768×1024, 1024×768, 1440×900, 844×390. Горизонтального переполнения нет, 6 плиток доступны, изображения загружаются, выбор Classic обновляет заголовок, C возвращает серверы. Для A после коррекции рамки iframe повторены точные ширины; первый проход был на 2px уже. Это адаптивная проверка Chromium внутри iframe, НЕ физический Android, НЕ аппаратный benchmark и НЕ эмуляция Android Chrome.

## Фактический обход публичной части

Выполнены 24 HTTP GET-проверки: страницы, robots/sitemap и публичные API; отдельно браузерный обход миров/каталогов/служебных страниц. Ни один голос, платёж, claim или обращение не отправлен. Формы входа не ремонтировались.

| Раздел | Результат | Предел проверки |
|---|---|---|
| Главная, L2, Minecraft, GTA RP | HTTP200, контент H1 и canonical в HTML | Главная проверена HTTP и открытием; миры дополнительно открыты в браузере. Не все серверные карточки осмотрены поштучно. |
| L2 — раскрытие хроник | VERIFIED LIVE: Все, Interlude, High Five, Essence, Classic, Gracia Final | Реальный URL Gracia — /lineage-2/gracia-final. Проба /lineage-2/gracia дала404 и НЕ считается сломанной ссылкой сайта. |
| L2 — поиск | VERIFIED LIVE: запрос без совпадений даёт понятное пустое состояние, очистка возвращает обычное состояние | Клиентская фильтрация, без отправки пользовательских данных. |
| Каталоги L2/MC/GTA | HTTP200, страницы открываются, корректно подписан выбранный мир; горизонтального переполнения на проверенном desktop нет | Обход каркасов и навигации; загрузочные состояния не считаются постоянной ошибкой. Не полная проверка всех комбинаций фильтров. |
| Рейтинг, открытия, избранное | HTTP200, браузерные страницы/пустые состояния открываются | Голосование и синхронизация избранного между аккаунтами не проверялись. |
| Профиль L2Play.su | HTTP200, H1/canonical; предыдущий live-срез подтвердил аватар/матовость/фон/Support | В этой сессии без повторной отправки действий. Физический свайп не проверен. |
| Владельцам | HTTP200; подтверждена старая формулировка «Топ по онлайну» | Нужна редактура под текущие три блока. В старом исходнике есть generic discord.gg, но в живом DOM он НЕ найден — не считать живой сломанной кнопкой. Действующий контакт mailto присутствует. |
| Добавление сервера | HTTP200, noindex; страница открыта | Отправка и принятие сервера требуют рабочего аккаунта, отложены. |
| Правообладателям | HTTP200, форма отображается | Обращение не отправлялось; доставка и админская обработка не приняты. |
| Политика и соглашение | HTTP200, H1/canonical в HTML | Юридическое содержание/реквизиты не приняты; финальный этап. |
| robots.txt / sitemap.xml | HTTP200 | Это не доказательство индексации в поисковых системах. |
| Неизвестный адрес | HTTP404 | Ожидаемое поведение, не поломка. |
| /api/v1/games, /servers?limit=1 | HTTP200 в пакетном проходе | Последующие отдельные запросы из технического окружения получили403; причина не установлена, это не доказательство падения сайта. |
| /api/v1/auth/me | HTTP503 | Подтверждает незакрытый вход. Исправление по указанию владельца отложено. |

Время HTTP-запросов из рабочего окружения не используется как оценка скорости посетителя: оно включает сеть и ограничения среды.
